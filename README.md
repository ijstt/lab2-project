# Lab 2

Лабораторная работа №2 — модули и функции в Python.

## Содержание

- `calculator.py` — модуль с арифметическими операциями
- `greeter.py` — модуль форматирования приветствий

## Пример использования

```python
from calculator import add
from greeter import greet

print(add(2, 3))       # 5
print(greet("World"))  # Hello, World!
```
